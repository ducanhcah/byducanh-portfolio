# byducanh. — Portfolio cá nhân

Portfolio cá nhân được xây dựng bằng Next.js 15, React 19, TypeScript và CSS, với nội dung dựa trên CV của Nguyễn Đức Anh.

## Chạy dự án trên máy cục bộ

```bash
npm install
npm run dev
```

## Build dự án

```bash
npm run build
```

## Tính năng

- Giao diện tối giản với phong cách biên tập hiện đại, sử dụng tông màu tối, font chữ Plus Jakarta Sans và các điểm nhấn chữ nghiêng Newsreader.
- Favicon trình duyệt dạng SVG với logo chữ ba dòng `by / duc / anh` và điểm nhấn màu xanh chanh.
- Thanh điều hướng responsive, chuyển đổi giao diện sáng/tối, tự động thu nhỏ phần đầu trang khi cuộn, hiệu ứng xuất hiện cho các phần nội dung và hỗ trợ chế độ giảm chuyển động.
- Tích hợp trình phát nhạc YouTube tùy chọn cho bài hát *Color Your Night*. Nhạc chỉ phát khi người dùng chủ động nhấn nút phát và phụ thuộc vào chính sách của trình duyệt.
- Hiển thị thông tin liên hệ với chức năng sao chép nhanh, cùng các liên kết GitHub và Facebook đã được xác minh từ CV.
- Không sử dụng ảnh chân dung hoặc tự thêm kinh nghiệm làm việc, số liệu thành tích, chứng chỉ hay trình độ kỹ năng chưa được xác thực.

## Lưu ý về nội dung

Portfolio bao gồm dự án PCSTORE cùng thông tin học vấn và kỹ năng được cung cấp trong CV.

Trước khi công khai website, hãy kiểm tra lại thời gian thực hiện dự án và bảo đảm các liên kết công khai đã sẵn sàng để chia sẻ.
